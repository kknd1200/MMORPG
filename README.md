# 새벽의 대지 — 웹 MMORPG 프로토타입

클래식 2D MMORPG 스타일의 브라우저 게임 프로토타입입니다. 빌드 도구 없이 HTML5 Canvas + ES 모듈로 동작합니다.

## 실행

```bash
npm start        # http://localhost:8080
npm test         # 성장/전투 공식 단위 테스트
```

> ES 모듈을 쓰므로 `index.html`을 파일로 직접 열면 동작하지 않습니다. 반드시 서버로 실행하세요.
> 현재 계정/캐릭터는 브라우저 localStorage에만 저장됩니다 (서버 붙이기 전 단계).

## 게임 흐름

로그인/회원가입 → 캐릭터 선택(최대 4개) → 캐릭터 생성(직업 선택 + 스탯 배분) → **새싹 마을(초보자의 마을)** 에서 시작

## 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 (땅) | 그 위치로 이동 (길찾기). 누른 채 움직이면 계속 따라 이동 |
| 좌클릭 (몬스터) | 다가가서 계속 일반공격 |
| 좌클릭 (NPC) | 대화 / 상점 |
| F5 ~ F12 | 해당 단축칸의 스킬·아이템 바로 사용 |
| 마우스 휠 | 단축칸 선택 이동 |
| 휠 클릭 | 선택된 단축칸 사용 |
| 드래그 | 스킬창/인벤토리에서 단축칸으로 등록, 단축칸끼리 교환 |
| 단축칸 우클릭 | 칸 비우기 |
| C / I / K / Esc | 캐릭터 / 인벤토리 / 스킬 / 메뉴 |

> 브라우저에 따라 F11(전체화면), F12(개발자도구)는 페이지에서 막을 수 없을 수 있습니다. 그럴 때는 휠 선택 + 휠 클릭으로 사용하세요.

## 직업

| 직업 | 주스탯 | 시작 HP/MP | 레벨업 HP | 레벨업 MP | 일반공격 |
|---|---|---|---|---|---|
| 기사 | 힘 | 40 / 20 | 8~12 | 3~5 | 10 (근접) |
| 요정 | 민첩 | 35 / 25 | 6~10 | 4~7 | 8 (원거리) |
| 마법사 | 지능 | 25 / 35 | 4~7 | 7~11 | 3 (근접) |
| 사제 | 지능 | 30 / 30 | 5~9 | 5~9 | 5 (근접) |

## 공식 (`js/systems/stats.js`)

- **스탯**
  - 힘: 근접 직업 주스탯 → 공격 명중, 스킬 피해
  - 민첩: 원거리 직업 주스탯 → 공격 명중, 스킬 피해
  - 지능: 마법 직업 주스탯 → 마법 명중, 스킬 피해
  - 체력: 공통 → 방어력(`체력/3`), 레벨업 HP 보너스(`(체력-10)/2`, 최소 0)
- **캐릭터 생성**: 직업 기본 스탯 + 보너스 6포인트 배분 (생성 시 스탯 최대 18)
- **일반공격력** = 직업 기본 + 무기 + 버프
- **스킬 피해** = 주스탯 × 일반공격력 × 스킬계수 (±10%)
  - 예) 기사 강타: 힘 18 × 일반공격 10 × 0.15 = 27
- **물리 명중** = 70% + (주스탯-10)×2% + (레벨차)×2% − 회피
- **마법 명중** = 80% + (지능-10)×2% + (레벨차)×2% − 마법저항×0.5
- **레벨업**: HP = 직업 주사위 + 체력 보너스, MP = 직업 주사위
- **보너스 포인트**: 10, 20, 30, 40, 50레벨에 1점, 51레벨부터 매 레벨 1점
- **축캐 / 저주캐**: 레벨업 주사위 합(체력 보너스 제외)이 평균에서 얼마나 벗어났는지(z점수, HP 60% + MP 40%)로 판정. 레벨업 3회부터 표시
  - z ≥ 1.5 축복받은 캐릭터(축캐) · ≥ 0.5 우수 · 평범 · ≤ −0.5 불운 · ≤ −1.5 저주받은 캐릭터(저주캐)

## 몬스터 / 사냥터

| 사냥터 | 몬스터 |
|---|---|
| 동쪽 초원 (Lv.1~3) | 초록 슬라임, 들쥐(무리), 독버섯 |
| 남쪽 숲 (Lv.4~8) | 회색 늑대(무리), 멧돼지, 고블린(무리), 고블린 궁수(원거리), 숲 거미 |
| 북쪽 폐허 (Lv.8~13) | 해골 병사, 폐허의 망령(원거리 마법), 오크 전사(무리), **보스: 오크 족장** |

- **무리(social)**: 한 마리를 건드리면 반경 6칸 안의 같은 종류가 함께 덤빕니다.
- **원거리(projectile)**: 사거리 안에서 멈춰서 화살/마탄을 쏩니다. 마법 공격(`magic`)은 방어력을 절반만 적용받습니다.
- **보스**: 사냥터당 한 마리만 존재하고, 처치 후 `respawn`초(오크 족장 120초) 뒤 다시 나타납니다. 미니맵에 깜빡이는 점으로 표시됩니다.
  - 오크 족장 **내려찍기**: 7초마다 플레이어 발밑에 붉은 원을 1.1초 예고한 뒤 반경 2.4칸에 공격력 ×1.8 피해. 원 밖으로 피하면 맞지 않습니다.
- 새 몬스터 추가: `js/data/monsters.js` 에 항목 추가 → `SPAWN_ZONES` 에 가중치로 등록. 그림은 `shape` 로 고르며 `js/game/sprites.js` 의 `SHAPES` 에 있는 것(slime, rat, mushroom, wolf, boar, goblin, spider, skeleton, wraith, orc)을 재사용하거나 새로 추가합니다.

## 그래픽

모든 그림은 이미지 파일 없이 캔버스 도형으로 그립니다 (`js/game/sprites.js`).

- 캐릭터: 직업별 외형(`LOOKS`), 8방향, 걷기·공격·시전 동작, 피격 시 붉은 번쩍임, 사망 시 쓰러짐. 무기 색은 장착 무기, 몸통은 장착 갑옷(가죽/사슬)에 따라 바뀝니다.
- 몬스터: 걷기·공격 동작, 피격 시 흰 번쩍임, 사망 시 사라짐. 보스는 발밑 붉은 기운과 [보스] 이름표.
- 미리보기: `npm start` 후 http://localhost:8080/tools/sprites.html (모든 직업 8방향 + 모든 몬스터 애니메이션)

## 새 직업 추가하기

1. `js/data/classes.js` 의 `CLASSES` 에 항목 추가 (주스탯, 시작 HP/MP, 성장 범위, 일반공격, 시작 장비, 색상)
2. `CLASS_ORDER` 에 id 추가 → 캐릭터 생성 화면에 자동 표시
3. `js/data/skills.js` 에 그 직업의 스킬 추가 (`classId` 지정)
4. `js/data/items.js` 에 전용 무기 추가 (`classes: ['새직업']`), 필요하면 `SHOPS.smith` 에 등록
5. `js/game/sprites.js` 의 `LOOKS` 에 외형 추가 (없으면 기사 외형으로 그려짐)

## 구조

```
index.html, css/style.css
js/main.js              화면 흐름 (로그인 → 선택 → 생성 → 게임)
js/data/                직업 · 스킬 · 아이템 · 몬스터 데이터
js/systems/stats.js     성장/전투 공식 (DOM 없음, 테스트 대상)
js/systems/storage.js   계정/캐릭터 저장 (localStorage)
js/game/world.js        맵 생성, 충돌, A* 길찾기
js/game/game.js         게임 루프, 이동, 전투, 스킬, 아이템, 입력
js/game/render.js       캔버스 렌더링 (타일, 이펙트, 이름표/체력바)
js/game/sprites.js      캐릭터 · NPC · 몬스터 스프라이트 그리기
tools/sprites.html      스프라이트 미리보기 (개발용)
js/game/hud.js          HUD, 단축칸, 각종 창, NPC 상점
tests/                  node:test 단위 테스트
```
