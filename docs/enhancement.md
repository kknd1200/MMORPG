# 드롭 옵션·대장간·장비 강화 — 2026-11-24

## 장비 개체와 무작위 수치

몬스터 또는 상자에서 장비를 얻을 때마다 별도 `gear_…` ID를 만든다. 기본 공격/방어 수치는 원본 기준의 80~120%에서 소수점 둘째 자리까지, 기존 부가 옵션은 기준의 50~150%에서 소수점 넷째 자리까지 뽑는다. 옵션 종류는 원본 장비를 따른다. 같은 장비를 여러 개 획득해도 수치·강화 단계가 공유되지 않는다.

뽑은 수치는 캐릭터의 `itemInstances`에 저장한다. 인벤토리 이동·장착·용병에게 전달·저장·재접속 시 다시 뽑지 않는다. 기존 저장 장비와 상점 구매 장비는 고정 수치를 유지한다. 상점 장비도 개체 ID를 사용하며, 기존 장비는 최초 강화 시 기존 능력치를 그대로 보존한 개체로 전환한다. 원본 카탈로그를 수정하거나 개체를 상점에 등록하지 않는다.

## 대장간

흑운 단검에 해당하는 아이템 레벨 36까지의 일반 장비만 판매한다. 금속 장비는 구리·철·강철·흑운까지이며 다른 재질의 장비도 같은 레벨 상한을 적용한다. 세트와 보스 고유 장비는 판매하지 않는다. 기존 초보 장비는 유지한다.

## 강화

인벤토리의 **무기/방어구 강화 주문서를 더블클릭 → 가방 또는 파티원이 착용한 장비 선택**으로 1회 시도한다. 선택 목록에 다음 강화 단계와 정확한 성공 확률, 실패 시 파괴 경고를 표시한다. 주문서 정보창의 사용 버튼이나 단축칸으로도 같은 선택창을 열 수 있다. 주문서는 잡화상에서 무기 500G, 방어구 300G에 구매하거나 몬스터 드롭으로 획득한다.

| 대상 강화 단계 | 무기 성공 확률 | 대상 강화 단계 | 방어구 성공 확률 |
|---|---:|---|---:|
| +1~+6 | 100% | +1~+4 | 100% |
| +7 | 13% | +5 | 13% |
| +8 | 3% | +6 | 3% |
| +9 | 1.5% | +7 | 1.5% |
| +10 이상 | 0.5% | +8 이상 | 0.5% |

확률은 현재 단계가 아닌 **도달할 다음 단계**에 적용한다. 성공마다 무기 공격력 +1 또는 방어구 방어력 +1이며, 이미 뽑힌 옵션 수치는 변하지 않는다. 성공과 실패 모두 주문서 1장을 소모한다. 실패 시 선택한 장비만 즉시 파괴하며 착용 중인 장비라면 해당 칸을 비운다. 장신구는 무기/방어구 강화 대상에서 제외한다. 상한은 별도로 두지 않는다.

선택 후 장비가 바뀌었거나 주문서가 없으면 아무것도 소모하지 않는다. 결과창을 표시하고 선택 상태를 해제하여 더블클릭이 추가 강화로 이어지지 않게 한다. 강화 결과는 즉시 저장한다.

## 검증

`npm test`의 강화 테스트는 정확한 확률 경계, 100% 구간, 개체별 무작위 값·영속성, 공격/방어 합산, 동일 장비 분리, 파티원 착용 장비 파괴, 잘못된 주문서/변경된 대상/중복 클릭의 무소모, 가방 포화, 대장간 상한과 강화 선택창을 확인한다.
