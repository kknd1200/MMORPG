# 액티브 2개·패시브 2개 선택

현재 캐릭터별 보유 목록은 액티브 4종과 패시브 4종이며 각각 2개까지 장착한다. 파티 창(P)에서 플레이어 또는 용병을 고른 뒤 액티브는 드래그해 배치하고, 패시브는 두 선택 상자에서 고른다. 선택하지 않은 액티브는 수동 단축칸에서도 시전할 수 없고, 선택하지 않은 패시브는 능력치에 반영하지 않는다. 패시브는 MP를 소모하지 않으며 일반공격 전용 자동사냥에서도 작동한다.

기존 40개 액티브 정의와 그림은 삭제하지 않는다. 기존 캐릭터는 배치해 두었던 액티브를 우선해 보유 4종에 보존하고 앞의 2개를 장착한다. 새 캐릭터는 직업별 기본 4종을 받으며 기존 해금 레벨을 따른다. 용병은 기존에 저장된 개인별 액티브 4종과 개인 해금 레벨을 유지한다. 패시브 4종은 모두 처음부터 선택 가능하다.

| 직업 | 패시브 4종 |
|---|---|
| 기사 | 수호자의 갑주, 전투 집중, 방패 숙련, 강인한 생명 |
| 전사 | 투사의 힘, 야성의 일격, 피의 갈증, 불굴 |
| 궁수(요정) | 매의 눈, 급소 포착, 숲의 발걸음, 정밀 조준 |
| 마법사 | 마력 숙련, 통찰, 원소 연구, 시전 집중 |
| 사제 | 신앙의 힘, 회복의 기도, 수호의 은총, 마나의 샘 |

현재 프로젝트에 패시브 정의가 남아 있지 않아 이 프로젝트의 기존 전투 옵션에 맞춰 20종을 정의했다. 각 효과와 수치는 파티 창에 표시한다. 공격·방어·명중·치명타·막기·흡혈·피해 감소·스킬 피해·재사용 시간·이동·자연 회복에 연결했으며 기존 일반공격 1초 간격은 유지한다. 자연 회복 패시브는 기존 자연 회복 가능 조건과 주기를 따른다.

초기 선택은 처음 두 패시브이며 바꿀 수 있다. 중복 장착은 두 칸을 교환하며 중복 합산하지 않는다. 다른 직업의 패시브는 장착할 수 없다. 선택과 미장착 상태는 저장·재접속·레벨업 후에도 유지한다. 기존 장비·강화·성장·개인 용병 기술은 유지한다.

검증은 `npm test`: 전 직업 4+4 목록과 2+2 장착, 기존 저장 변환, 빈 칸 유지, 선택 효과/해제/직업 제한/중복 방지, 수동 시전 제한, 용병별 목록 보존, 파티 UI를 확인한다.
