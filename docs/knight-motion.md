# 기사 무기 동작

남녀 기사의 대기, 걷기, 일반공격, 스킬은 각각의 손 위치와 무기 방향을 사용한다. 남기사의 동작 값을 여기사에 공통 적용하지 않는다. 8방향의 400개 원본 포즈를 기준으로 장착한 한손검·한손도끼·방패를 합성하며, 방패 강타는 기존의 돌진·충돌·끌어오기 프레임 시간표를 유지한다.

원본에 붙어 있던 방패를 제거하고 팔·닫힌 장갑을 복원했다. 등과 옆을 보일 때는 망토와 몸통이 무기 및 방패의 앞을 가릴 수 있다. 검과 도끼의 손가락은 손잡이 앞에, 방패를 쥔 왼손은 방패 면 뒤에 표시한다.

- 기사 전용 확인: 서버 실행 후 `/tools/knight-motion-review.html`
- 남녀 맨손/착용 상태를 나란히 재생하고, 장비·방향·동작·속도를 선택한다.
- `tools/rig/knight-poses.json`: 프레임별 손 좌표·무기 방향·앞뒤 순서
- `tools/rig/knight-left-arms.webp`: 원본 방패 아래의 팔을 복원한 16개 방향별 원화 패치
- 원화/포즈 수정 후 `python tools/rig/build_equipment_rig.py knight knight_female`
- 부유 위치 검사: `python tools/rig/check_knight_grips.py`
- 회귀 검사: `npm test`

프레임 검사와 실제 게임 Canvas 렌더러의 연속 프레임 출력을 검증했다. 자동 Chromium은 실행 환경의 소켓 제한으로 시작하지 못했으므로 브라우저 직접 플레이 검증은 포함하지 않는다.
