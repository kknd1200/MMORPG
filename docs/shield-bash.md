# 방패 강타 — 돌진 후 주변 몬스터 끌어오기

사용자 요청에 따라 기존 단일 타격을 전용 동작과 실제 강제 이동으로 연결했다. 남녀 기사 모두 기존 원화와 8방향 시트를 사용하며, 머리 위로 검을 들어 올리는 준비 프레임을 제외하고 방패 자세를 중심으로 12단계 프레임 순서·유지 시간·기울기를 따로 구성했다. 이미지 파일을 교체하지 않는다.

| 시간 | 동작 |
|---|---|
| 0.00~0.15초 | 몸을 낮추고 방패를 앞세워 준비 |
| 0.15~0.32초 | 대상 앞까지 실제 위치 이동 |
| 0.32초 | 방패 충돌 이펙트의 4번 프레임부터 재생하며 대상 1회 타격 |
| 0.39~0.72초 | 안쪽으로 수축하는 범위 효과와 함께 주변 몬스터를 끌어오기 |
| 0.72~1.00초 | 무기와 방패를 회수하고 기본 자세로 복귀 |

끌어오기 반경은 별도 지정이 없어 **3칸**으로 설정했다. 시전 사거리 **1.3칸**, MP **8**, 기본 재사용 **5초**, 피해 계수 **힘 × 일반공격 × 0.2**, 대상 감속 **3초**는 유지한다. 끌어온 주변 적에게 별도의 추가 피해는 주지 않는다. 주변 적은 시전자와 겹치지 않는 거리까지만 이동한다.

돌진과 끌어오기는 0.06칸 이하의 구간으로 전체 경로의 충돌과 시야를 검사한다. 벽·나무 너머의 적은 대상에서 제외하고, 진행 중 장애물이 생기면 막힌 곳에서 멈춘다. 죽거나 다른 맵으로 이동하면 남은 동작과 끌어오기 상태를 해제한다. 동작 중 일반공격·다른 스킬·일반 이동이 전용 동작을 덮어쓰지 않으며, 일반공격의 기존 절대 쿨타임은 유지한다.

다른 스킬의 광역 모양과 수치는 변경하지 않았다.

검증: `npm test`. 남녀·8방향 프레임 선택, 준비/돌진/충돌/회복 시간, 실제 몬스터 위치 변화, 한 번의 MP 소모와 한 번의 타격, 벽/나무/얇은 장애물/시야 변경, 사망·맵 변경·대상 제거, 리더·용병 동작 잠금을 확인한다.
