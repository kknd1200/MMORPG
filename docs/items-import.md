## 적용 범위

- 장비 513종: 장착 부위·직업·레벨 제한, 반지 두 칸, 양손 무기/방패 충돌 검사, 용병 장비 회수, 모든 부위 공격·방어 합산.
- 원거리 무기는 원거리 칸에 장착하며 일반 무기와 동시에 능력치를 받지 않는다. 기존 저장 데이터의 활은 기존 무기 칸에서도 정상 적용된다.
- 일반 장비와 재료/물약은 상점에 추가했다. 이후 대장간 판매 상한은 흑운 등급(아이템 레벨 36)으로 제한했다. 상점은 이름 검색·분류·24종씩 페이지 이동을 지원한다. 지역 세트와 고유 장비는 네임드/보스 드롭이다.
- 드롭은 레벨 ±12 범위를 사용한다. 새 장비/재료/상자 전체 드롭 예산은 일반 몬스터 2.5%/15%/0.6%, 네임드 3배, 보스 5배이며 각 분류 후보 수로 나눈다. 기존 드롭은 유지한다.
- 20종 상자는 원본의 가중치와 수량을 사용해 1종을 뽑는다. 가방 공간이 부족하면 상자와 아이템을 잃지 않는다.
- 공격력·피해 감소·치명타·명중·스킬 재사용·흡혈·경험치·골드·막기·스킬 피해·추가 타격·약화된 적/보스 피해 옵션을 연결했다. 세트의 2/4부위 효과도 같은 집계에 포함한다.
- 원본의 무작위 능력치 생성은 이 게임에 없으므로 기본 공격·방어의 기준값은 현재 성장 곡선에 맞췄다. 이후 드롭 장비의 개체별 무작위 수치와 강화는 [강화 문서](enhancement.md)를 따른다. 원본 메타데이터는 `rebirth-item-source.js`에 보존했다.

## 아직 연결하지 않은 효과

제작·생활 기술·화살 소모는 기존 게임에 없으므로 해당 물품은 보관·판매할 수 있다. 생활 물약은 현재 사용 불가로 표시한다. 공격속도 옵션은 사용자 지정 일반공격 간격(모든 직업 1초)을 유지하기 위해 적용하지 않는다. 추가 최대 HP·반사·독 옵션도 현재 이관 범위에서는 적용 대기로 표시한다. 이러한 미적용 옵션은 활성 능력치 합계에 넣지 않는다.
