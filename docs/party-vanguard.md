# 기사·전사 용병 선봉 대형 — 2026-11-24

기사·전사 용병은 고용 순서와 관계없이 플레이어 앞 약 2.2칸을 선봉 자리로 사용한다. 여러 명이면 좌우로 나란히 펼친다. 궁수·마법사·사제 용병은 후방 약 1.7칸에 선다. 대형의 앞쪽은 플레이어의 이동 목적지, 현재 공격 대상, 바라보는 방향 순서로 결정한다.

고용·맵 입장·부활·멀리 떨어진 용병 합류에도 같은 역할 대형을 적용한다. 벽이나 나무로 자리가 막히면 시야가 닿는 가까운 빈자리를 택하고, 평상시 이동과 전투 접근은 기존 길찾기를 사용한다.

자동사냥에서는 기사·전사 용병이 플레이어의 공격/탐색 목표를 공유한다. 원거리 플레이어가 사거리에서 멈춰도 근접 용병은 자신의 공격 사거리까지 전진해 공격한다. 아직 플레이어 주변 11칸에 들어오지 않은 탐색 목표도 공유하므로, 탐색 중 뒤쪽 대형에만 머무르지 않는다. 대상이 없으면 직접 탐색 대상으로 향한다.

플레이어가 직접 이동 명령을 내리는 동안은 전투 때문에 뒤에 남지 않도록 선봉 대형 합류를 우선한다. 선봉 합류에는 기존의 30% 따라잡기 속도 보정을 적용한다. 사망 상태·플레이어와의 거리 제한·스킬 전용 동작 잠금은 유지한다. 근접 접근이 막히면 경로를 다시 구한다. 일반공격 간격은 기존 1초이며 스킬·장비·성장·고용 순서는 바꾸지 않는다.

검증: `npm test`. 기사/전사 및 두 자동사냥 모드에서 원거리 플레이어보다 앞으로 이동해 실제 근접 공격하는지, 8방향 대형과 복수 선봉 배치, 먼 탐색 목표 공유, 벽/나무 우회, 고용·부활·맵 입장, 수동 이동 우선과 거리 제한을 확인한다.
