# 직업별 명중과 일반공격 간격 — 2026-11-24

| 직업 | 일반공격·공격 스킬 명중 기준 | 일반공격 간격 |
|---|---|---:|
| 기사·전사 | 힘 | 1초 |
| 궁수(요정) | 민첩 | 1초 |
| 마법사·사제 | 지능 | 1초 |

플레이어와 용병, 수동 일반공격과 자동사냥 모두 같은 규칙을 사용한다. 스킬의 피해 계산에 사용하는 값과 명중 계산을 분리하여, 명중은 항상 해당 직업의 주 능력치를 읽는다. 기존 명중 증가량(상한 전 주 능력치 1당 +2%p), 레벨 차이, 물리 회피/마법 저항 보정과 명중 상한은 유지한다. 마법사·사제의 일반공격도 마법 명중 계산을 사용한다.

장비와 물약의 명중 보너스는 한 번만 적용한다. 기존 물리 공격 스킬에서 중복 적용되던 보너스를 제거했다. 캐릭터 창에 일반공격 명중·공격 스킬 명중·일반공격 간격을 표시한다.

일반공격은 마지막 공격 시작부터 최소 1초 간격이며 대상 변경·자동사냥 모드 변경·상대 타이머 초기화로 우회할 수 없다. 스킬 동작이 진행 중이면 그 동작이 끝날 때까지 일반공격을 시작하지 않는다. 스킬의 MP·재사용 시간, 원거리 사거리, 방패 강타의 돌진·끌어오기 동작은 유지한다.

몬스터 생성의 기존 기준 DPS 계산은 기존 간격을 별도 기준선으로 보관한다. 플레이어 공격 속도 변경이 몬스터 HP·공격력 등의 자동 상향으로 이어지지 않는다.

검증: `npm test`. 전 직업의 플레이어/용병 실제 일반공격·공격 스킬 명중 판정, 무관한 능력치와의 분리, 명중 보너스 중복 방지, 캐릭터 표시 수치, 일반공격 1초 간격과 스킬 동작 보호, 기존 몬스터 수치를 확인한다.
